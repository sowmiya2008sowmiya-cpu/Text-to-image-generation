# Day 8 – Exploring AI Image Generation Tools

## 📌 Overview

This repository contains my **Day 8 activity** on exploring Generative AI image generation tools.

The activity focuses on understanding how **text prompts can be converted into creative and visually appealing images using Generative AI**.

## 🎯 Objective

To explore AI image generation tools and understand how effective text prompts influence the creativity, quality, and style of generated images.

## 🛠️ Tools Explored

| Tool         | Purpose                   |
| ------------ | ------------------------- |
| NightCafe AI | AI Image Generation       |
| Craiyon AI   | Text-to-Image Generation  |
| Leonardo AI  | Creative Image Generation |

## ✨ Activities

### 1. NightCafe AI

* Created multiple images using descriptive text prompts.
* Explored different creative styles and concepts.
* Observed how detailed prompts affect the generated results.

### 2. Craiyon AI

* Created creative images using simple text prompts.
* Explored fantasy, space, and futuristic concepts.

### 3. Leonardo AI

* Generated creative fantasy and futuristic images.
* Experimented with different visual concepts and styles.

## 💡 My Observation

The quality and style of the generated image depend greatly on the prompt given to the AI tool.

Clear, creative, and descriptive prompts can produce more attractive and imaginative images. Different AI image generation tools can also produce different visual results from similar prompts.
